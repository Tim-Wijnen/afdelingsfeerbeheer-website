# Afdelingsfeer Balloons

Laad eerst de stylesheet:

```html
<link rel="stylesheet" href="balloon-font.css">
```

Gebruik daarna het font rechtstreeks:

```css
.feesttitel {
  font-family: "Afdelingsfeer Balloons", sans-serif;
}
```

Of gebruik de meegeleverde goudafwerking:

```html
<h1 class="balloon-font">Gefeliciteerd!</h1>
```

De webfont bevat A-Z, a-z, 0-9 en de veelgebruikte tekens uit
`letters/glyph-map.json`. `WOFF2` is de primaire webfont; `TTF` is de fallback.
